# Зависимости и лицензии

Прямые production-зависимости React, React DOM, React Router, TanStack Query и Zod используют MIT; lucide-react — ISC; шрифт Manrope — SIL OFL 1.1. Тексты уведомлений поставляемых runtime-пакетов скопированы из установленных зависимостей в `public/licenses/` и доступны в production `/licenses/NOTICE.txt`. Исходный дизайн предоставлен пользователем проекта; лицензия архива не переопределяется.

Версии зафиксированы `package-lock.json`. Для воспроизводимой установки используется `npm ci`. Серверный MAX Bridge загружается с официального CDN и не копируется в bundle. Проверка npm при установке зависимостей: 0 известных vulnerabilities; это не аудит безопасности всего приложения.
