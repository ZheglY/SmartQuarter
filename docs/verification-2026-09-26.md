# Проверка приложения, 26 сентября 2026

Проверена локальная рабочая версия ветки `feat/house-identity-service` поверх
`549b708`. Изменения предыдущего серверного исправления перенесены в локальный

закоммичены, не опубликованы и не развёрнуты на VPS.

## Изменения

- Навигация сохраняется при загрузке, отсутствии дома, отказе в доступе и
  неизвестном маршруте. Внутренние страницы имеют переход назад.
- Администратор назначает и снимает председателей через `/admin`, включая
  назначение на существующий дом. Снятие полномочий отзывает управление и
  ожидающие передачи роли, сохраняя доступ жителя.
- Регистрация домов доступна одобренным председателям и администраторам.
  Миграция Identity сохраняет полномочия существующих активных председателей.
- Реализованы опросы и результаты голосования, календарь с редактированием и
  удалением, инициативы с поддержкой и завершением.
- Обновлены gRPC, REST/OpenAPI, клиентские схемы, миграции и CI.
- Добавлен `DATA-API.yaml` и исходный валидатор с лицензией и указанием источника.

## Воспроизведение

Из корня репозитория:

```sh
docker compose -f deploy/test/compose.yaml run --build --rm test
bash deploy/test/check-provision.sh
python tools/data-api/validate_data_api.py DATA-API.yaml --openapi contracts/openapi/openapi.yaml
```

Для frontend используйте команды из `web/miniapp/package.json` и
`web/miniapp/README.md`. PostgreSQL-тест Community включается через
`COMMUNITY_TEST_DATABASE_URL` с отдельной БД `community_test`;
`COMMUNITY_TEST_MIGRATE=1` применяет миграции. Не направляйте тесты на рабочую БД.

В финальном локальном прогоне интеграционный тест запускался из заранее собранного
Linux-бинарника в том же изолированном Compose-проекте `smartquarter-acceptance`.
Это позволяет использовать уже загруженные зависимости. После проверки тестовый
стенд остановлен; рабочие серверные контейнеры не затрагивались.

## Границы проверки

- Внешний MAX в интеграционных тестах заменён тестовым HTTP-сервером; браузерные
  тесты используют подготовленные API-ответы. Реальные MAX Android/iOS, вход через
  Bridge, серверные сертификаты и доставка сообщений требуют приёмки после деплоя.
- DATA-API содержит 15 проверок и очистку созданного события. Валидатор проверяет
  структуру и соответствие OpenAPI, но не выполняет HTTP-сценарии на VPS.

- Повторное SSH-подключение к VPS 26 сентября завершилось тайм-аутом порта 22.
